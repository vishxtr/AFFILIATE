## 🔒 Security Recommendations

After creating your admin account:

1. **Change Default Password** - Use a strong, unique password
2. **Use Real Email** - For password recovery
3. **Enable 2FA** - In Supabase dashboard (optional but recommended)
4. **Limit Admin Access** - Only create admin accounts for trusted users

## ❓ Troubleshooting

**"Invalid credentials" error?**
- Make sure you created the user in Supabase Dashboard
- Check that "Auto Confirm User" was enabled
- Try resetting the password

**Can't access Supabase Dashboard?**
- You need the Supabase project owner access
- Check your Supabase account at https://supabase.com/dashboard

**Forgot admin password?**
- Go to Supabase Dashboard → Authentication → Users
- Find the user and click "Reset Password"
